Hack Club's Half Life W2 project! A custom 3D-printed case for the PCB designed for Week 1. #YSWS

## What is it?

This is a custom 3D case designed to hold the PCB board for dexterbie. The print is divided in top and bottom. The top part has holes so the MX Switches, DHT11 sensor, screen and some pins are visible and fully operational. The top and bottom parts connect through screws and brass heat-set inserts. It has a small hole in the front side so the USB-C port of the ESP32 microcontroller is accessible.

## How was it designed?

This case was designed in Onshape, a CAD software that runs entirely on your browser. I learned how to use it with YouTube tutorials and the [W2 starter project guide](https://github.com/karnxx/merbl/blob/main/guide.md).

## Repo structure

This repository contains STEP models inside ```/CAD```. Printable .STL files are found inside ```/printables```.

This repository is synced with the Half Life platform, which means it contains auto-generated files (JOURNAL.md, BOM.csv -> Edited by me)
